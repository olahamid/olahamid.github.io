Modulo Labs · gatta.io

smart contract engineer / security researcher

Built an Intel TDX attestation and zero-knowledge stack that ties each campaign's reward root to the code that produced it, verified on-chain.

Technical detail
  • Intel TDX quotes that commit each campaign's reward root to the code image.
  • A Rust worker that compresses each quote into a small Groth16 proof (SP1 zkVM).
  • A Noir circuit for anonymous reward claims.
  • Four audit reports on the stack, with 17 findings.

Closed source, but I'm happy to walk through it on a call.
